# Le Four du Canal — démo GitHub

Page HTML pédagogique pour le live Uncode School : une image, un titre, un sous-titre et un bouton « Je participe ».

## Voir la page en local

Dans ce dossier, lancer `python3 -m http.server 8000`, puis ouvrir `http://localhost:8000/`.

Le bouton affiche une confirmation côté navigateur. Il ne collecte aucune donnée et ne crée aucune inscription.

## Fichiers

- `index.html` : structure et contenu de la page.
- `style.css` : mise en page et adaptation mobile.
- `script.js` : confirmation affichée après le clic.
- `assets/patisseries.jpg` : photographie de Toby Do, [source sur Unsplash](https://unsplash.com/photos/a-display-case-filled-with-lots-of-pastries-3SzrEtFYk8E).

Ce concours est fictif et sert uniquement à illustrer un flux GitHub.
